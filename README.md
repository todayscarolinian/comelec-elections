# COMELEC Elections (live-voting)

Online registration and voting app replacing the election commission's Google Form. Built with Next.js (App Router), TypeScript and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
